# Configuration

This category lists vNext's main `appsettings.json` configuration sections by host (Orchestration, Execution, DbMigrator): URL Templates, Service Discovery, Caching, Telemetry, Workflow Execution, Caller Role Provider, Python, Scripting/Sandbox, Server Timeout, and Header Limits. Every host uses standard .NET configuration layering, with environment variables in `Section__SubKey` form.
