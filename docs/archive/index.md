# Arşiv

Bu bölümdeki dokümanlar **güncelliğini yitirmiştir** ve yalnızca referans amacıyla saklanmaktadır. Güncel geliştirme akışı için [Getting Started](/docs/getting-started/) bölümünü takip edin.

- **[Local Development](./local-dev)** — Docker Compose ile manuel runtime kurulumu. Yerini [Geliştirme Ortamı Kurulumu (Forge)](/docs/getting-started/forge-setup) aldı.
- **[Multi-Domain Kurulumu](./multi-domain)** — Birden fazla domain'i elle yapılandırma. Domain ve environment yönetimi artık [vNext Forge](/docs/tools/forge-studio) üzerinden yapılıyor.
